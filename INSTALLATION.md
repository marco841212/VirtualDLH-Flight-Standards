# VirtualDLH Flight Standards Monitor

## Installation

1. Install dependencies:

npm install

2. Build plugin:

npm run build

3. Upload the generated package through the Stratos plugin manager.

4. Enable VirtualDLH Flight Standards Monitor.

## Modules

- Aircraft profiles
- Flight phase monitoring
- Lighting checks
- Procedure scoring
- Pilot ranking
- Crew Center integration

## Testing

Run a controlled test flight before production deployment.
